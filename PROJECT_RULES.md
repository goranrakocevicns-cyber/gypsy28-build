# Gypsy 28 — obavezna pravila rada

## KRITIČNO UPOZORENJE

**NE KORISTITI NETLIFY NI POD KOJIM USLOVIMA.**

Za Gypsy 28 je zabranjeno koristiti Netlify za:
- produkciju,
- preview,
- testiranje,
- fallback,
- backup,
- privremeni hosting,
- deployment ili bilo kakvu pomoćnu varijantu.

Pre bilo kakve izmene, testa ili deploymenta na ovom projektu prvo proveriti ovo pravilo.

Koristiti postojeću GitHub infrastrukturu projekta. Ako neki zadatak nije moguće uraditi bez Netlify-a, zaustaviti se i ne uvoditi Netlify kao alternativu.
